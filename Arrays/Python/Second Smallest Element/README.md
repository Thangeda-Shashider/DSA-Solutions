# Second Smallest Element

This repository contains a Python implementation to find the second smallest element in an array of integers.

## Problem Statement

Given an array of integers `arr` of size `n`, return the second smallest numerical value among all elements in the array.

### Examples

**Example 1:**
- **Input:** `n = 5`, `arr = [4, 2, 9, 7, 5]`
- **Output:** `4`
- **Explanation:** The smallest element is `2`, and the second smallest element is `4`.

**Example 2:**
- **Input:** `n = 5`, `arr = [2, 3, 3, 2, 1]`
- **Output:** `2`
- **Explanation:** The unique elements are `1, 2, 3`. The second smallest element is `2`.

## Constraints

- $1 \le n \le 10^3$
- $0 \le arr[i] \le 10^3$

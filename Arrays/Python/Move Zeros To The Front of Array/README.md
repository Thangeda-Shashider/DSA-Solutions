# Move Zeros to the Front of an Array

## Problem Description

You are given an array of integers `arr` of size `n`. Your task is to move all the zeros in the array to the front while preserving the relative order of the non-zero elements.

### Constraints

* `1 <= n <= 10^4`
* `-10^6 <= arr[i] <= 10^6`

### Input Format

* The first line of input contains an integer `n`.
* The second line of input contains `n` space-separated integers representing the elements of `arr`.

### Output Format

* The output represents the modified array after moving all zeros to the front.

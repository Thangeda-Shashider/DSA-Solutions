# Pascal's Triangle

A Python solution to generate the first `N` rows of Pascal's Triangle.

## Problem Description

Given an integer `N`, return the first `N` rows of Pascal's Triangle.

Pascal's Triangle is a triangular array of numbers where each number is the sum of the two numbers directly above it.

### Example 1
```text
Input:  N = 3
Output: {{ 1 }, { 1, 1 }, { 1, 2, 1 }}
Explanation: The first 3 rows of Pascal's triangle are: { {1} , {1, 1} , {1, 2, 1} }.
